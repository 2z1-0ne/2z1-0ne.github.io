Project Overview

This website presents a research project on glaucoma diagnosis using artificial intelligence. The proposed model, VF-RefineNet, refines visual field measurements by using retinal nerve fiber layer (RNFL) thickness maps from OCT images.

The goal of this study is to improve the consistency between structural and functional eye exams and to enhance glaucoma discrimination performance.

Learn More

Why This Research Matters

Glaucoma is one of the leading causes of irreversible blindness. In clinical practice, doctors use both structural imaging and functional testing, but these results often do not match well. This project addresses that problem by using AI to refine visual field data in a clinically meaningful way.
